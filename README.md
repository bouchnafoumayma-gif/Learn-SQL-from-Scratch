# SQL Fundamentals

Welcome to **SQL Fundamentals**! This repository contains learning materials and practical examples designed to introduce beginners to SQL (Structured Query Language) and relational database management.

## 📚 Course Content

The course covers the following topics:

- Introduction to SQL and relational databases
- Understanding tables, rows, columns, and data types
- SQL statements and their categories
- Creating and managing databases and tables
- Inserting, updating, and deleting data
- Retrieving data using `SELECT`
- Filtering data using `WHERE`
- Sorting results using `ORDER BY`
- Aggregate functions (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`)
- Grouping data using `GROUP BY` and `HAVING`
- Relationships between tables
- Joining tables using `JOIN`

## 🎯 Objectives

By the end of this course, you should be able to:

- Understand the fundamentals of relational databases.
- Write basic SQL queries.
- Retrieve and manipulate data.
- Understand relationships between database tables.
- Perform basic data analysis using SQL functions.

## 💻 Practical Examples

This repository includes SQL queries, code examples, and exercises to help beginners practice and reinforce their knowledge.
